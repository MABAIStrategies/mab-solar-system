# MAB AI Strategies — Solar System Site

Cinematic one-domain multi-route website for [MAB AI Strategies](https://mabaistrategies.com).

Scroll-driven first-person journey through themed stations (mechanism, services, proof, command, convergence), with a client portal and Command vault.

## Local

```bash
python -m http.server 8765
```

Open `http://127.0.0.1:8765`.

## Tests

```bash
npm test
```

## Deploy

Static files on Vercel. Preview (pre-production) is the default `vercel` deploy; production uses `vercel --prod`.
